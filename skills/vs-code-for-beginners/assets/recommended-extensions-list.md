# Recommended Extensions for Your Setup

Ready-to-install list for VS Code + Markdown + Code Projects.

---

## Install These First (Tier 1)

### Essential Extensions

**1. Markdown Preview Enhanced**
- **What it does**: Better markdown preview with more features
- **Why you need it**: Side-by-side editing and preview
- **Search for**: "Markdown Preview Enhanced"
- **Install**: Click "Install"

**2. Prettier - Code formatter**
- **What it does**: Auto-formats your code
- **Why you need it**: Keeps code consistent and clean
- **Search for**: "Prettier"
- **Install**: Click "Install"

**3. GitLens — Git supercharged**
- **What it does**: Shows Git history and info in code
- **Why you need it**: See who changed what and when
- **Search for**: "GitLens"
- **Install**: Click "Install"

**4. Error Lens**
- **What it does**: Shows errors inline in your code
- **Why you need it**: Spot problems without hovering
- **Search for**: "Error Lens"
- **Install**: Click "Install"

**5. Markdown All in One**
- **What it does**: Keyboard shortcuts for markdown formatting
- **Why you need it**: Format faster with `Cmd + B`, `Cmd + I`, etc.
- **Search for**: "Markdown All in One"
- **Install**: Click "Install"

## How to Install Extensions

1. **Open Extensions Panel**: `Cmd + Shift + X`
2. **Search**: Type extension name
3. **Click Install**: Wait for installation
4. **Reload** (if prompted): Click "Reload"

---

## Managing Extensions

### See What You Have

`Cmd + Shift + X` → Shows all installed

### Disable an Extension

Right-click → "Disable"

Useful if:
- Extension causes problems
- You want to test without it
- You don't need it right now

### Uninstall an Extension

Right-click → "Uninstall"

When to uninstall:
- You're not using it
- It conflicts with another
- It slows down VS Code

## Don't Overload

⚠️ **Too many extensions = slower VS Code**

- Start with Tier 1
- Add Tier 2 as you discover needs
- Uninstall unused extensions
- Keep it lean

---

## Pro Tips

1. **Read Reviews**: Look at star ratings and reviews
2. **Check Downloads**: Popular extensions usually work well
3. **Read README**: Each extension has documentation
4. **Test Each One**: Add one, use it, see if you like it
5. **Disable Before Uninstall**: Test disabling first
6. **Updates**: VS Code auto-updates most extensions
