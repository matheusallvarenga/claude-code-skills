# VS Code Keyboard Shortcuts Cheatsheet

Quick reference for the most important shortcuts.

---

## The Essential 5 (Learn These First)

```
Cmd + Shift + P    Command Palette (run ANY command)
Cmd + P            Quick Open (open file by name)
Cmd + F            Find in file
Cmd + H            Find and replace
Cmd + G            Go to line
```

---

## File Operations

```
Cmd + N            New file
Cmd + O            Open file
Cmd + S            Save
Cmd + Alt + S      Save all
Cmd + W            Close file/tab
Cmd + K, Cmd + W   Close all files
Ctrl + Tab         Switch between files
```

---

## Editing

```
Cmd + X            Cut line
Cmd + C            Copy line
Cmd + V            Paste
Cmd + Z            Undo
Cmd + Shift + Z    Redo
Cmd + Shift + K    Delete line
Cmd + Shift + D    Duplicate line
Cmd + /            Toggle comment
Cmd + Shift + I    Format document
```

---

## Movement

```
Cmd + G            Go to line
Cmd + F8           Next error
Cmd + Shift + F8   Previous error
Cmd + L            Select line
Cmd + A            Select all
```

---

## Search

```
Cmd + F            Find in file
Cmd + H            Find and replace
Cmd + Shift + F    Find in all files
Cmd + G            Go to next match
Cmd + Shift + G    Go to previous match
```

---

## Interface

```
Cmd + B            Toggle sidebar
Cmd + J            Toggle terminal
Cmd + Shift + E    Show file explorer
Cmd + Shift + F    Show search
Cmd + Shift + G    Show Git
Cmd + Shift + X    Show extensions
Cmd + K, Z         Zen mode
```

---

## Zoom

```
Cmd + +            Zoom in
Cmd + -            Zoom out
Cmd + 0            Reset zoom
```

---

## Extensions & Markdown (With Extensions)

```
Cmd + B            Bold (Markdown All in One)
Cmd + I            Italic (Markdown All in One)
Cmd + Shift + V    Markdown preview
```

---

## Pro Tips

- **Most Powerful**: Cmd + Shift + P (Command Palette)
- **Most Used**: Cmd + S (Save)
- **Learn 3 This Week**: Pick 3 shortcuts and use them constantly
- **Muscle Memory**: Repetition makes it automatic
- **Reference**: Cmd + K, Cmd + S to see all shortcuts

---

## Remember

You don't need to memorize all of these. Start with The Essential 5, add 3-4 new ones each week. Within a month, you'll be much faster!
