# VS Code Daily Checklist & Tips

Use this checklist to build productive VS Code habits.

---

## Morning Startup Routine

- [ ] Open VS Code
- [ ] Open your project (File → Open Folder)
- [ ] Check Git status (`Cmd + Shift + G`)
- [ ] Pull latest changes (`git pull` in terminal)
- [ ] Open the file you're working on
- [ ] Take a sip of water ☕

---

## While Working

### Every Hour
- [ ] Save file (`Cmd + S`)
- [ ] Stretch and look away from screen (eye health!)
- [ ] Check your progress

### Frequently
- [ ] Use keyboard shortcuts (building muscle memory)
- [ ] Preview markdown side-by-side (`Cmd + Shift + V`)
- [ ] Check for errors (Error Lens shows them inline)
- [ ] Keep terminal visible for quick tests

### When Making Changes
- [ ] Make meaningful edits (one task at a time)
- [ ] Test changes in terminal (`Cmd + J`)
- [ ] Format code (`Cmd + Shift + I`)
- [ ] Save file (`Cmd + S`)

---

## Committing Progress

When you finish a task:

- [ ] Review changes (`Cmd + Shift + G`)
- [ ] Check diff to see what changed
- [ ] Stage files you want to commit
- [ ] Write clear commit message
- [ ] Commit changes
- [ ] Push to GitHub (`git push`)

**Or in terminal**:
```bash
git add .
git commit -m "Your message"
git push
```

---

## End of Day

- [ ] Commit any pending work
- [ ] Push to GitHub
- [ ] Review what you accomplished
- [ ] Note what's next for tomorrow
- [ ] Close VS Code

---

## Weekly Maintenance

### Every Week
- [ ] Check for extension updates
- [ ] Review your keyboard shortcuts (learning progress?)
- [ ] Clean up unused files/branches
- [ ] Update VS Code (if available)

## Productivity Tips

### Start Slow
- Don't try to learn everything
- Master one workflow at a time
- Add complexity gradually

### Use Keyboard
- Click is fine for learning
- Transition to keyboard as you go
- Shortcuts make you 10x faster

### Take Breaks
- Look away every hour
- Stretch neck and shoulders
- Rest your eyes (eye strain is real)

### Stay Organized
- Close unused tabs
- Clean up file explorer
- Keep one project open at a time

### Save Frequently
- `Cmd + S` is your friend
- Save after every logical change
- Better than losing work

### Test Often
- Run code frequently
- Don't wait for huge session
- Small tests catch bugs early

### Commit Regularly
- Commit after each feature
- Don't accumulate huge changes
- Makes debugging easier

## Common Mistakes to Avoid

❌ **Don't**:
- Install too many extensions at once
- Forget to save before closing
- Skip committing for days
- Leave terminal messy
- Click when you could use keyboard
- Open 20 tabs at once

✅ **Do**:
- Start simple
- Save frequently
- Commit regularly
- Keep terminal organized
- Learn keyboard shortcuts gradually
- Keep focused on one task

## Your Daily Ritual

```

```

