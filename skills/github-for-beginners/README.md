# GitHub for Beginners Skill

Complete learning resource for mastering GitHub and Git, from absolute beginner to proficiency.

## What's Inside

### Reference Files (`references/`)

1. **git-basics.md** - Foundational concepts
   - Git vs GitHub distinction
   - Key concepts: repositories, commits, branches, merges
   - Mental models and analogies
   - Why these patterns matter

2. **commands-reference.md** - Complete command dictionary
   - Every common command you'll need
   - Organized by frequency and workflow
   - Examples for each command
   - Explanations of what happens

3. **workflows.md** - Step-by-step procedures
   - Complete workflows for common tasks
   - Initial setup through daily operations
   - Troubleshooting integrated workflows
   - Integration with Claude Code

4. **troubleshooting.md** - Problems and solutions
   - Common issues organized by category
   - Diagnostic questions
   - Step-by-step solutions
   - Prevention tips

5. **claude-code-integration.md** - Using Claude Code with GitHub
   - How the integration works
   - Best practices for requesting changes
   - Reviewing Claude's work
   - Common use cases and patterns

### Quick Reference (`assets/`)

- **quick-checklist.md** - Daily checklist for common tasks
  - Before/during/after work
  - Command quick reference
  - Emergency commands
  - Red flags to avoid

## How to Use This Skill

### For Learning Concepts
When you want to understand **why** something works:
- Start with `git-basics.md`
- Read the foundational concepts
- Understand mental models

### For Practical Help
When you want to **do something**:
- Check `quick-checklist.md` for quick reference
- Read relevant workflow in `workflows.md`
- Step-by-step instructions with explanations

### For Command Reference
When you need to **remember a command**:
- Check `commands-reference.md`

- Includes examples

### When Something Goes Wrong

- Check `troubleshooting.md`
- Find your problem
- Follow diagnostic questions

### Using with Claude Code
When you want to **use Claude Code with GitHub**:
- Read `claude-code-integration.md`

## Progressive Learning Path

### Week 1-2: Fundamentals
1. Read `git-basics.md` - understand key concepts
2. Follow "Setting Up Git" in `workflows.md`
3. Do "Your First Commit" workflow
4. Reference `commands-reference.md` as needed

### Week 3-4: Daily Work
1. Practice creating branches
2. Make multiple commits
3. Create your first Pull Request
4. Learn to handle merge conflicts

### Month 2: Team Work
1. Review pull requests from teammates
2. Help resolve merge conflicts
3. Use Claude Code for features
4. Dive deeper into advanced workflows

### Month 3+: Mastery
1. Mentor teammates
2. Optimize workflows
3. Handle complex scenarios
4. Automate and improve processes

## Key Principles

**Progressive Disclosure**: Learn what you need when you need it. Don't overwhelm yourself with information.

**Practical First**: Focus on doing things before understanding theory.

**Clear Explanations**: Every concept is explained in simple terms.

**Real Examples**: All examples are practical and based on real workflows.

**Evolution**: This skill grows with you - from beginner to proficiency.

## Quick Start

1. **Never used Git?**
   - Read `git-basics.md` first (30 minutes)
   - Then follow "Setting Up Git" in `workflows.md`

2. **Want to start using GitHub?**
   - Read relevant workflow in `workflows.md`
   - Reference `commands-reference.md` as needed
   - Check `quick-checklist.md` daily

3. **Stuck on a problem?**
   - Check `troubleshooting.md`
   - Find your error type
   - Follow the solution steps

4. **Using Claude Code?**
   - Read `claude-code-integration.md`
   - Learn best practices
   - Review example use cases

## Reference Structure

All information is organized for easy lookup:

- **By Task**: Look in `workflows.md` for step-by-step procedures
- **By Concept**: Look in `git-basics.md` for explanations
- **By Command**: Look in `commands-reference.md` for syntax
- **By Problem**: Look in `troubleshooting.md` for solutions
- **By Integration**: Look in `claude-code-integration.md` for Claude Code help

## Tips for Success

1. **Bookmark `quick-checklist.md`** - Use it every day
2. **Understand, don't memorize** - Focus on understanding why, not memorizing commands
3. **Practice regularly** - Make commits daily
4. **Read error messages** - They usually tell you what's wrong
5. **Review before committing** - Always check `git diff` first
6. **Ask for help** - If stuck, ask teammates or check troubleshooting
7. **Keep learning** - GitHub has more features as you advance
