Activate shadcn/ui MCP integration.

Command: npx shadcn@latest mcp

Capabilities:
- List available components
- Add components to project
- Configure themes
- Customize variants

Components Available:
Accordion, Alert, AlertDialog, AspectRatio, Avatar,
Badge, Button, Calendar, Card, Checkbox, Collapsible,
Command, ContextMenu, Dialog, Drawer, DropdownMenu,
Form, HoverCard, Input, Label, Menubar, NavigationMenu,
Pagination, Popover, Progress, RadioGroup, ScrollArea,
Select, Separator, Sheet, Skeleton, Slider, Switch,
Table, Tabs, Textarea, Toast, Toggle, Tooltip

Example operations:
- "Add the Button component"
- "Install Dialog and Form components"
- "List all available components"
- "Configure dark theme"

Requirements: React + Tailwind CSS project initialized.
