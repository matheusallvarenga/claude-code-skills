Activate Markitdown MCP (Built-in).

Document conversion to Markdown.

Supported Formats:
- Microsoft Office: .docx, .xlsx, .pptx
- PDF: .pdf
- Images: .png, .jpg (with OCR)
- HTML: .html, .htm

Capabilities:
- Convert documents to Markdown
- Extract text from PDFs
- Preserve document structure
- Handle tables and lists
- OCR for images

Example operations:
- "Convert this PDF to Markdown"
- "Extract text from the Word document"
- "Transform Excel to Markdown table"
- "Read content from PowerPoint slides"

Use Cases:
- Document analysis
- Content migration
- Format conversion
- Text extraction

Output: Clean, structured Markdown preserving original formatting.
