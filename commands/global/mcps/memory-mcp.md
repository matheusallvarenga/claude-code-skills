Activate Memory MCP (Built-in).

Persistent memory between sessions.

Operations:
- save_memory(key, value)  - Save information
- get_memory(key)          - Retrieve information
- list_memories()          - List all memories
- delete_memory(key)       - Delete memory
- search_memories(query)   - Search memories

Use Cases:
- User preferences
- Project decisions
- Recurring patterns
- Important references
- Long-term context

Example operations:
- "Save that the user prefers Tailwind CSS"
- "Remember that this project uses PostgreSQL"
- "Store the API endpoint for future reference"
- "Retrieve all memories about this project"

Best Practices:
- Use descriptive keys
- Organize by category
- Update outdated memories
- Clean up irrelevant data

Memory persists across Claude Code sessions.
